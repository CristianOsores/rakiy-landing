# Rakiy

*Cuentas claras en casa, sin perseguir a nadie.*

Landing Page de Rakiy, una aplicación para dividir los gastos compartidos entre las personas que viven juntas. Permite registrar gastos, dividirlos, ver quién le debe a quién y registrar pagos.

Está hecha solo con HTML, CSS y JavaScript, y es una sola página responsive que se adapta a Desktop, Tablet y Mobile.
